CSS Box Model

Box Model Demonstration

Every HTML element is represented as a rectangular box. The CSS Box Model contains four main parts: Content, Padding, Border and Margin.

Content Area

Four Parts of the Box Model

1. Content: The actual text, image or information inside an element.

2. Padding: The space between the content and the border.

3. Border: The line surrounding the padding and content.

4. Margin: The space outside the border that separates elements.

Width and Height Calculation

Content width: 200px

Left and right padding: 20px + 20px

Left and right border: 8px + 8px

Total width: 200 + 40 + 16 = 256px

Content height: 100px

Top and bottom padding: 20px + 20px

Top and bottom border: 8px + 8px

Total height: 100 + 40 + 16 = 156px

Box Sizing: Border Box

The box-sizing property changes how the total width and height are calculated. With border-box, padding and border are included inside the given width and height.

Border Box

With border-box: Total width = 200px and total height = 100px.
